# Titanic-Survival-Prediction
Titanic survival prediction using machine learning (Python, Pandas, Scikit-learn)
## Overview
This project predicts whether a passenger survived using machine learning.

- Data Visualization

## Key Insights
- Females had higher survival rates
- First-class passengers survived more
- Family size influenced survival

- Accuracy: ~80.5%
